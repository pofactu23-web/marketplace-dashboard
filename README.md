# Кадровый ресурс

Презентационный сайт кадрового агентства: главная страница и три вакансии. Статические HTML-страницы генерируются Node.js без внешних зависимостей. Форм, базы кандидатов, аналитики и сбора документов нет.

## Локальный запуск

Нужен Node.js 20 или новее.

```sh
npm ci --ignore-scripts
npm run dev
```

Сервер работает на порту 3000. Для другого порта задайте `PORT`. `npm run dev` пересобирает сайт перед запуском; после изменения файлов повторите запуск. `npm start` запускает уже собранный каталог `dist`.

## Проверка

```sh
npm run build
npm test
```

Тесты проверяют тексты вакансий, условия НПД, зарплаты, внутренние ссылки, метаданные и отсутствие форм и наличие указанной почты.

## Публикация

Сайт можно разместить на статическом хостинге, например Netlify. Настройки: команда сборки `npm run build`, папка публикации `dist`.

Перед окончательной сборкой задайте переменную `SITE_URL` равной реальному HTTPS-адресу сайта без завершающего `/`. Тогда генератор добавит абсолютные Open Graph URL, canonical и sitemap. Адрес не придуман заранее: до публикации домен неизвестен.

Пример команды (замените адрес собственным):

```sh
SITE_URL=https://your-real-domain.example npm run build
```

Прямые ссылки:

- `/vacancies/beauty-admin`
- `/vacancies/gymnastics-admin`
- `/vacancies/marketplace-manager`

Каждый маршрут содержит собственный `index.html` и метаданные: для Telegram не требуется исполнение JavaScript. Хостинг должен обслуживать каталоги с `index.html` по чистым URL. Обложки PNG 1200×630 уже включены в `public/covers`. Отдельные данные вакансий находятся в `src/data.mjs`, шаблоны в `scripts/build.mjs`, стили в `public/styles.css`.

После публикации проверьте прямые ссылки и предпросмотр в Telegram: он может сохранять прежнюю обложку в кеше. Сам сайт не открывает чаты автоматически.

Сведения о требованиях к кандидатам, не предоставленные в задании, обозначены как требующие уточнения у менеджера. Для вопросов указана предоставленная почта lina.nikrasova.83@mail.ru. Неподтверждённые партнёры, отзывы и гарантии не добавлены.

После сборки выполните `node scripts/preview.mjs`. Файл `/workspace/kadroviy-resurs-v2.html` содержит весь сайт, стили и страницы вакансий. Навигация работает без JavaScript. Этот файл предназначен для скачивания и просмотра; для публикации отдельных URL используйте каталог `dist`.
